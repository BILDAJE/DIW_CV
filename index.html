Guía para crear tu Currículum Vitae

Bienvenido al apartado de creación de tu Currículum Vitae. En esta página encontrarás una pequeña guía que te ayudará a preparar tu currículum paso a paso.

Antes de comenzar, te recomendamos leer las indicaciones de cada apartado para saber qué información debes incluir.

¿Cómo preparar tu currículum?

  1. Lee las indicaciones de cada apartado.
  2. Prepara la información que vas a necesitar.
  3. Comprueba que los datos sean correctos y estén actualizados.
  4. Accede a tu currículum para consultar su estructura.

Apartados del currículum

1. Datos personales

En este apartado debes incluir tus datos de contacto para que las empresas puedan identificarte y comunicarse contigo.

  • Nombre y apellidos.
  • Teléfono fijo y teléfono móvil.
  • Correo electrónico.
  • Localidad de residencia.
  • Fotografía personal, si deseas incluirla.
Consejo para este apartado

Comprueba que tu teléfono y correo electrónico sean correctos. Utiliza una dirección de correo adecuada para el ámbito profesional.

2. Formación académica

Aquí debes indicar los estudios que has realizado, comenzando preferiblemente por los más recientes.

  • Nombre del título o estudios.
  • Centro educativo donde los realizaste.
  • Año de inicio.
  • Año de finalización.
Consejo para este apartado

Incluye tus titulaciones oficiales y los estudios que estés cursando actualmente.

3. Tecnologías

En este apartado debes indicar los lenguajes de programación, herramientas y tecnologías que conoces.

  • Lenguajes de programación.
  • Lenguajes de marcado y estilos.
  • Bases de datos.
  • Entornos de desarrollo.
  • Nivel de conocimiento de cada tecnología.
Consejo para este apartado

Indica únicamente las tecnologías que hayas utilizado o que conozcas. Sé realista al valorar tu nivel.

4. Habilidades

Las habilidades permiten mostrar tus capacidades personales y profesionales.

  • Trabajo en equipo.
  • Responsabilidad.
  • Comunicación.
  • Resolución de problemas.
  • Capacidad de aprendizaje.
  • Organización y planificación.
Consejo para este apartado

Selecciona las habilidades que realmente te representen y que puedan ser útiles en el puesto de trabajo al que quieras acceder.

5. Idiomas

Indica los idiomas que conoces y tu nivel de conocimiento de cada uno.

  • Nombre del idioma.
  • Nivel de comprensión.
  • Nivel hablado y escrito.
Consejo para este apartado

No exageres tu nivel de conocimiento. Es importante indicar un nivel que puedas demostrar.

6. Experiencia laboral

En este apartado debes incluir los trabajos que hayas realizado anteriormente.

  • Nombre de la empresa.
  • Puesto desempeñado.
  • Descripción de las tareas realizadas.
  • Año de inicio.
  • Año de finalización.
Consejo para este apartado

Comienza por tu experiencia más reciente y explica brevemente las principales tareas que realizabas. Si todavía no has trabajado, puedes dejar este apartado sin experiencia laboral.

7. Otros datos

Puedes utilizar este apartado para incluir información adicional que pueda resultar interesante para una empresa.

  • Carnet de conducir.
  • Disponibilidad horaria.
  • Disponibilidad para viajar.
  • Disponibilidad para realizar prácticas.
  • Otros datos de interés.
Consejo para este apartado

Añade solamente información relevante para el tipo de trabajo que estás buscando.

Antes de continuar

Antes de consultar tu currículum, comprueba que tienes preparada toda la información necesaria.

  • Revisa la ortografía.
  • Comprueba que los datos de contacto sean correctos.
  • Utiliza información actualizada.
  • Evita incluir información innecesaria.

¿Todo preparado?

Cuando hayas revisado las indicaciones y tengas preparada la información, puedes acceder a la vista de tu Currículum Vitae.
